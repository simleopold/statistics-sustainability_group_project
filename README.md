# A STATISTICAL ANALYSIS OF SOCIAL BACKGROUND, EDUCATIONAL PATHWAYS, AND CAREER SUSTAINABILITY

This repository contains the analysis code and results for a longitudinal study examining how social background influences educational outcomes over time in Ireland.

The project uses data from the Growing Up in Ireland (GUI) study, spanning four developmental waves from childhood to early adulthood. While the raw data is not publicly available due to licensing and privacy restrictions, all code, model outputs, and reproducible analysis scripts are included for transparency.
